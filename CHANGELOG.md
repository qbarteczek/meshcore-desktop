# Changelog

## 0.2.0-dev – 2026-10-09

First public developer preview.

- Universal device support: Bluetooth LE (automatic PIN pairing on Windows), USB serial and TCP companions; saved devices.
- Messages with delivery confirmation, per-device history, unread markers and sound.
- Contacts tab with sorting, filtering and clean-up of stale contacts.
- Remote management of repeaters, room servers and sensors over the mesh (login, status, telemetry, neighbours, CLI).
- USB text console for directly connected repeaters.
- Scheduled link test with CSV log; cadence survives application restarts.
- Device configuration, channel management, JSON backup and restore.
- Developer tab: radio packet log, event log, library command box.
- English and Polish interface; language chosen in the installer.
- Windows installer (per-user, no administrator rights).

## 0.1.0 – 2026-10-09

Private prototype for a single device (messages, link test, device settings).
